# АртВитраж — сайт компании

Одностраничный сайт на **Next.js 15 (App Router) + Tailwind 4**: услуги, онлайн-калькулятор, галерея работ, заявки в Telegram и на e-mail, фоновая музыка.

Все данные лежат в `data/*.json`, поэтому тексты, услуги и цены меняются **без правки кода**. Всё, что помечено `TODO`, сейчас заглушка, и его нужно заменить реальными данными (чек-лист в конце).

## Запуск

```bash
npm install
cp .env.example .env   # заполните ключи (см. ниже)
npm run dev            # http://localhost:3000
npm run build && npm start
```

## Как добавить услугу

1. Добавьте запись в `data/services.json`, и больше ничего не нужно править:

```json
{
  "id": "partitions",
  "title": "Стеклянные перегородки",
  "description": "Офисные и межкомнатные перегородки из закалённого стекла.",
  "image": "/images/services/partitions.webp",
  "priceFrom": 9000,
  "unit": "за м²"
}
```

2. Положите фото в `public/images/services/partitions.webp` (1200×800, WebP).
3. Услуга сама появится в карточках, в выпадающем списке формы и в фильтре галереи.
4. *(по желанию)* Добавьте её в калькулятор: запись с тем же `id` в `data/calculator.json`. Если записи нет, услуги в калькуляторе просто не будет.
5. *(по желанию)* Добавьте фото работ в `data/works.json` с `"service": "partitions"`.

`id` латиницей, без пробелов, он должен быть уникальным.

## Калькулятор: цены и формулы

Файл `data/calculator.json`. **Сейчас там ДЕМО-цены**, замените их на реальные.

```json
"railings": {
  "quantity": "area",      // что считаем: "length" (пог. м), "area" (м²) или "count" (шт.)
  "unit": "м²",
  "basePrice": 7500,       // ₽ за единицу
  "minPrice": 20000,       // цена не ниже этой суммы
  "fields": [ ... ]
}
```

Формула: **цена = basePrice × количество × (произведение коэффициентов) + (доплаты)**, округляется до 100 ₽. Количество: для `area` это `ширина (или длина) × высота`.

Типы полей (`fields`):

| type | Параметры | Влияние на цену |
|---|---|---|
| `number` | `role` (`length` / `width` / `height`), `min`, `max`, `step`, `default`, `unit` | Задаёт количество |
| `select` | `options[]`: `value`, `label`, и **один из** `coef`, `add`, `addPerUnit` | `coef` умножает цену, `add` добавляет ₽, `addPerUnit` добавляет ₽ за каждую единицу |
| `checkbox` | `default`, `coef` / `add` / `addPerUnit` (применяются, когда галочка стоит) | как у `select` |

Чтобы добавить тип стекла или фурнитуру, добавьте строку в `options`. Чтобы добавить поле, добавьте объект в `fields`. Кнопка «Отправить расчёт менеджеру» сама передаёт все выбранные параметры и сумму в заявку.

## Заявки: Telegram и e-mail

Все ключи только в `.env` (локально) и в **Vercel → Project → Settings → Environment Variables** (на сайте). Файл `.env` в `.gitignore`, в репозиторий не попадает.

```
TELEGRAM_BOT_TOKEN=   токен бота
TELEGRAM_CHAT_ID=     id чата или группы
MAIL_TO=              куда дублировать заявки
SMTP_HOST=            например smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=            логин почты
SMTP_PASS=            пароль приложения
MAIL_FROM=            от кого (обычно = SMTP_USER)
```

Работает любой из каналов по отдельности. Заявка считается отправленной, если сработал хотя бы один. Если не настроен ни один, форма покажет «Приём заявок ещё не настроен» и номер телефона.

### Как создать Telegram-бота и узнать chat_id

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите имя бота (например, «АртВитраж Заявки») и username, оканчивающийся на `bot` (например, `artvitrage_leads_bot`).
3. BotFather пришлёт **токен** вида `123456:ABC-DEF…`. Это `TELEGRAM_BOT_TOKEN`. Никому его не показывайте.
4. Откройте своего бота и нажмите **Start**. Если заявки нужны в группе, добавьте бота в группу и напишите там любое сообщение.
5. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. В ответе найдите `"chat":{"id":123456789,…}`. Это `TELEGRAM_CHAT_ID`. У группы id отрицательный (`-100…`).
6. Вставьте оба значения в `.env` и в Vercel, затем **Redeploy**.

### Пароль для почты
Для Яндекса и Mail.ru создайте **пароль приложения** в настройках безопасности почты и используйте его как `SMTP_PASS`. Основной пароль от ящика сюда вписывать не нужно.

### Защита от спама
- **Honeypot:** скрытое поле `website`, боты его заполняют и получают «успех», но ничего не отправляется.
- **Лимит:** 5 заявок за 10 минут с одного IP (`lib/rate-limit.ts`). Лимит хранится в памяти сервера. Для высокой нагрузки замените на Upstash Redis.
- **Валидация:** на клиенте и на сервере (`lib/lead.ts`). Фото: JPG, PNG или WebP до 5 МБ.

## Яндекс.Метрика

Укажите номер счётчика в `NEXT_PUBLIC_YM_ID`. Счётчик подключится сам. Цель **«Отправка заявки»** имеет идентификатор `lead_submit`: создайте в Метрике цель типа «JavaScript-событие» с этим идентификатором.

## Цвета и анимации

Тема «Графит и золото». Все цвета лежат в одном месте: переменные в начале `app/globals.css` (`--bg`, `--surface`, `--ink`, `--gold`, `--gold-light`, `--on-gold` и др.). Поменяйте их, и сайт перекрасится целиком. Золотая кнопка использует тёмный текст `--on-gold` ради контраста.

Анимации включаются атрибутами: `data-magnetic` (кнопка тянется к курсору), `data-spotlight` (подсветка за курсором на карточке), `data-parallax` (смещение при прокрутке). Все они отключаются при `prefers-reduced-motion`.

## Объединение с перегородки-краснодар.рф

Сайт объединён со старым сайтом `перегородки-краснодар.рф` (Flexbe). Оттуда перенесено:
- **Услуги:** 10 видов конструкций (перегородки межкомнатные, офисные и сантехнические, стены и двери из стекла, ограждения лестниц, душевые, сауны и хаммамы, входные группы, зеркала) с их формулировками. Окна и остекление остались с нашей версии. Все услуги лежат в `data/services.json`.
- **Контакты:** три телефона (главный +7 918 351-75-46, он же в WhatsApp и Telegram), адрес Краснодар, ул. Петра Метальникова 5, корпус 2, режим «заявки принимаются круглосуточно» (`data/company.json`). Адрес на карте найден через OpenStreetMap, при необходимости поправьте `geo`.
- **Тексты:** раздел «О компании», преимущества («более 15 лет», цена фиксируется после замера, сроки, пожелания, проекты любой сложности) и ответы FAQ.
- **Фото:** 126 реальных фото работ, разложены по услугам в `public/images/works/<услуга>/`. Оригиналы (около 180 МБ) сжаты в WebP до 1400 px, итого 8 МБ. Не взяты 10 фото кухонь из категории «Зеркала на заказ» и 1 кадр стройплощадки: они не относятся к стеклу. Скрипты: `scripts/import-works.mjs` (раскладка фото и `data/works.json`) и `scripts/make-service-images.mjs` (картинки карточек и фон hero).

**Калькулятор.** У душевых, перил и окон демо-цены (TODO), как раньше. У остальных услуг режим `"mode": "quote"`: клиент указывает размеры, они уходят менеджеру в заявке без цены, как на старом сайте. Чтобы включить расчёт цены, добавьте `basePrice` и поля по образцу перил.

### Как подключить домен перегородки-краснодар.рф
Пока вы не переключите DNS, домен ведёт на Flexbe, и старый сайт работает как раньше. Когда проверите новый:
1. В Vercel откройте проект → **Settings → Domains → Add** и введите `перегородки-краснодар.рф` (если не примет, введите `xn----8sbajfcca3atc1bgahdsdgfq.xn--p1ai`). Добавьте и `www.`-вариант.
2. У регистратора домена замените DNS-записи на те, что покажет Vercel (обычно `A` для `@` на `76.76.21.21` и `CNAME` для `www` на `cname.vercel-dns.com`). Старые записи Flexbe удалите.
3. Подождите распространения DNS (от 10 минут до суток), Vercel сам выпустит сертификат.
4. В Vercel → Settings → Environment Variables задайте `NEXT_PUBLIC_SITE_URL=https://перегородки-краснодар.рф` и сделайте Redeploy (адрес попадёт в `sitemap.xml`, `robots.txt`, Open Graph и микроразметку).
5. Добавьте сайт в Яндекс.Вебмастер и перенесите счётчик Метрики (`NEXT_PUBLIC_YM_ID`), если он был на старом сайте.

Перед переключением сохраните настройки старого сайта (счётчики, формы, интеграции), чтобы ничего не потерять.

## Заставка и логотип

При первом заходе за сессию показывается заставка: логотип рисуется по центру экрана (3,35 с), затем уменьшается и перелетает в левый верхний угол, где остаётся логотипом шапки. Пропустить можно кликом, кнопкой «Пропустить» или клавишами Esc, Enter, пробел. Заставка не показывается повторно в той же сессии, при `prefers-reduced-motion` и на странице `/privacy`. Чтобы посмотреть её снова, откройте `/?intro`.

- **Отключить насовсем:** уберите `<Intro />` из `app/layout.tsx`.
- **Длительность:** переменная `--k` в блоке `.lg-play` файла `app/globals.css` (1 = версия 4,4 с из `brand/logo`, сейчас 0,75) и константа `PLAY_MS` в `components/Intro.tsx`.
- **Свой логотип:** замените слои в `brand/logo/logo-layers.svg` и выполните `node scripts/make-logo-component.mjs`, он пересоберёт `components/logo-markup.ts`. Цвет текста и рамки берётся из `currentColor`, поэтому логотип сам подстраивается под тёмную и светлую тему и белую шапку над hero.

## Логотип, тема, видео, «до и после»

- **Иконка вкладки:** `public/logo-mark.svg` и `app/icon.svg`. Логотип шапки и заставки собирается из `brand/logo` (см. выше).
- **Светлая и тёмная тема:** кнопка с солнцем и луной в шапке. По умолчанию тёмная, выбор хранится в `localStorage`. Цвета светлой темы лежат в блоке `:root[data-theme="light"]` файла `app/globals.css`.
- **Видео в hero:** положите ролик в `public/video/hero.mp4` (10–15 секунд, без звука, до 2–3 МБ, зацикленный) и впишите `"heroVideo": "/video/hero.mp4"` в `data/company.json`. Оно грузится только на широких экранах, без режима экономии трафика и без reduced-motion. Пока видео не загрузилось, виден постер (`public/images/hero/hero.webp`). Пустая строка отключает видео.
- **«До и после»:** пары фото лежат в `data/before-after.json`. Добавьте запись с путями к фото «до» и «после» (одинаковый ракурс и размер, 1200×800). Пока там стоит заглушка, замените её реальным объектом. Пустой список скрывает блок.

## Музыка

Файл `public/audio/bg.mp3`. **Сейчас там сгенерированный ambient-трек без прав третьих лиц** (`python3 scripts/make-ambient.py`). Чтобы поставить свой, положите mp3 поверх (лучше до 1–2 МБ, зацикленный).

Поведение: стартует после первого клика, нажатия клавиши или прокрутки, громкость 20%, плавное нарастание 2 с, повтор по кругу. Кнопка с эквалайзером в правом нижнем углу, выбор запоминается в `localStorage`. На мобильных по умолчанию выключено. Файл загружается только при первом запуске. Громкость и время нарастания меняются в `components/MusicToggle.tsx` (`VOLUME`, `FADE_IN_MS`).

> Браузеры запрещают автозапуск звука. Если страницу только прокрутили, часть браузеров может отклонить запуск, тогда музыка включится с первого клика.
