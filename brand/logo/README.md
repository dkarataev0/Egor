# Логотип «АртВитраж»: слои и анимация

Логотип перерисован вручную в SVG по исходному JPG. Текст переведён в кривые (Manrope: «Арт» Regular, «Витраж» Bold, подпись SemiBold).

## Файлы

| Файл | Что это |
|---|---|
| `logo-layers.svg` | Логотип с именованными слоями (`glass-back`, `glass-mid`, `frame-front`, `glass-front`, `text-art`, `text-vitrazh`, `tagline`) |
| `layers-2x/`, `layers-4x/` | PNG каждого слоя на прозрачном фоне (664×292 и 1328×584, один холст, слои совпадают при наложении) |
| `logo-2x.png`, `logo-4x.png` | Собранный логотип, прозрачный фон |
| `logo-animated.html` | Мягкая анимация 4,4 с, затем статичный кадр. Клик по логотипу проигрывает заново. При `prefers-reduced-motion` сразу финальный кадр. Параметры: `?w=1400` (ширина), `?bg=transparent` |
| `logo-glint-loop.html` | Вариант для сайта: логотип статичен, раз в 6 с плавно проходит блик (1,4 с) |
| `video/logo-1920x1080-60fps.mp4`, `video/logo-1080x1080-60fps.mp4` | Видео на белом фоне, 60 к/с, 5,5 с (4,4 с анимации и удержание), с размытием движения (4 суб-кадра, затвор 180°) |
| `video/logo-transparent.webm` | VP9 с прозрачным фоном, 1760×780, 60 к/с, 4,8 с, с размытием движения |
| `video/logo-preview.gif` | GIF 1000×460, 25 к/с, 0,84 МБ, зациклен |
| `preview-layers.png`, `check-overlay-50.png`, `preview-animation-frames.png` | Предпросмотр слоёв, сверка с оригиналом, кадры анимации |

## Тайминги анимации

| Время, с | Что происходит |
|---|---|
| 0,0–1,1 | Рамка `frame-front` прорисовывается (`stroke-dashoffset`), старт с середины левой стороны |
| 0,35–1,85 | Стёкла выезжают справа налево из-за рамки по очереди (задержка 0,15 с). Движение, прозрачность и размытие идут отдельными кривыми |
| 1,3–2,3 | «Арт»: мягкий сдвиг снизу и появление |
| 1,6–2,6 | «Витраж»: раскрытие маской слева направо с широкой мягкой кромкой |
| 2,2–3,65 | Подпись: буквы сходятся к финальному трекингу каскадом слева направо (12 мс на букву) |
| 3,05–3,9 | Точки-разделители появляются с лёгким масштабом |
| 3,3–4,4 | Блик под 30° плавно проходит по стёклам слева направо |

Кривые: движение `cubic-bezier(0.33, 0, 0.1, 1)` (спокойный старт, долгая посадка), прорисовка и маска `cubic-bezier(0.65, 0, 0.35, 1)`, прозрачность и размытие `cubic-bezier(0.25, 0.1, 0.25, 1)`. Они заданы переменными `--glide`, `--inout` и `--fade` в начале стилей HTML.

## Как пересобрать

Нужны Node 20+, ffmpeg и пакеты `opentype.js`, `sharp`, `playwright`. Шрифты Manrope берутся из `@fontsource/manrope` (файлы `manrope-cyrillic-*.woff`), путь к ним задан в `src/build.js`.

1. `node build.js` собирает `logo-layers.svg` из `params.json` (координаты, цвета, шрифты).
2. `node build-anim.js <папка>` собирает оба HTML.
3. `node export-layers.js <папка>` экспортирует PNG слоёв.
4. `node render-frames.js <html> <папка> <ширина окна> <высота окна> <ширина логотипа> <fps> <секунд> <1, если прозрачный фон> <суб-кадров, 4 даёт размытие движения> <затвор, 0.5>` снимает кадры, ffmpeg склеивает их в видео.
