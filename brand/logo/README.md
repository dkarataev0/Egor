# Логотип «АртВитраж»: слои и анимация

Логотип перерисован вручную в SVG по исходному JPG. Текст переведён в кривые (Manrope: «Арт» Regular, «Витраж» Bold, подпись SemiBold).

## Файлы

| Файл | Что это |
|---|---|
| `logo-layers.svg` | Логотип с именованными слоями (`glass-back`, `glass-mid`, `frame-front`, `glass-front`, `text-art`, `text-vitrazh`, `tagline`) |
| `layers-2x/`, `layers-4x/` | PNG каждого слоя на прозрачном фоне (664×292 и 1328×584, один холст, слои совпадают при наложении) |
| `logo-2x.png`, `logo-4x.png` | Собранный логотип, прозрачный фон |
| `logo-animated.html` | Анимация 3,2 с, затем статичный кадр. Клик по логотипу проигрывает заново. При `prefers-reduced-motion` сразу финальный кадр. Параметры: `?w=1400` (ширина), `?bg=transparent` |
| `logo-glint-loop.html` | Вариант для сайта: логотип статичен, раз в 6 с проходит блик |
| `video/logo-1920x1080-60fps.mp4`, `video/logo-1080x1080-60fps.mp4` | Видео на белом фоне, 60 к/с, 4,5 с (3,2 с анимации и удержание) |
| `video/logo-transparent.webm` | VP9 с прозрачным фоном, 1760×780, 60 к/с, 3,7 с |
| `video/logo-preview.gif` | GIF 1000×460, 25 к/с, 0,45 МБ, зациклен |
| `preview-layers.png`, `check-overlay-50.png`, `preview-animation-frames.png` | Предпросмотр слоёв, сверка с оригиналом, кадры анимации |
| `src/` | Скрипты сборки (см. ниже) |

## Тайминги анимации

| Время, с | Что происходит |
|---|---|
| 0,0–0,7 | Рамка `frame-front` прорисовывается (`stroke-dashoffset`) |
| 0,3–1,3 | Стёкла выезжают справа налево из-за рамки по очереди (задержка 0,15 с), прозрачность и размытие 0 → 1 |
| 1,1–1,7 | «Арт»: сдвиг снизу и появление |
| 1,4–2,0 | «Витраж»: раскрытие маской слева направо с мягкой кромкой |
| 1,9–2,6 | Подпись: трекинг сужается до финального, точки появляются с масштабом |
| 2,5–3,2 | Блик под 30° проходит по стёклам слева направо |

Кривая везде `cubic-bezier(0.22, 1, 0.36, 1)`, кроме блика: у него `cubic-bezier(0.45, 0, 0.25, 1)`, иначе он пролетает стёкла за 0,2 с.

## Как пересобрать

Нужны Node 20+, ffmpeg и пакеты `opentype.js`, `sharp`, `playwright`. Шрифты Manrope берутся из `@fontsource/manrope` (файлы `manrope-cyrillic-*.woff`), путь к ним задан в `src/build.js`.

1. `node build.js` собирает `logo-layers.svg` из `params.json` (координаты, цвета, шрифты).
2. `node build-anim.js <папка>` собирает оба HTML.
3. `node export-layers.js <папка>` экспортирует PNG слоёв.
4. `node render-frames.js <html> <папка> <ширина окна> <высота окна> <ширина логотипа> <fps> <секунд> <1, если прозрачный фон>` снимает кадры, ffmpeg склеивает их в видео.
