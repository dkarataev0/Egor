# Логотип «Свободное пространство» — анимация для hero-блока

Монохром: тушь `#111` на бумаге `#F7F7F5`. Анимация ~4 с, проигрывается один раз при загрузке.

| Время | Что происходит |
|---|---|
| 0–1.0 с | Знак рисуется линией (`stroke-dashoffset`): сначала проём, потом створка |
| 1.0–1.6 с | Створка приоткрывается: `rotateY(-68deg) → 0` с `perspective`, петля у левого косяка проёма |
| 1.4–2.4 с | Надпись проявляется шторкой слева направо (встречные `translateX`), разрядка сужается с 0.3em до нормы (сдвиг букв через `transform`) |
| 2.0–4.0 с | Скетч стадиона «рисуется пером»: SVG-маска из мазков по линиям крыш, затем конструкции, штриховка последней |

Easing везде `cubic-bezier(0.65, 0, 0.35, 1)`. Анимируются только `transform`, `opacity` и `stroke-dashoffset`.
Базовые стили описывают финальный кадр, поэтому при `prefers-reduced-motion: reduce` логотип сразу показан целиком.

## Вес

Скетч 34.8 КБ + шрифт 1.2 КБ + CSS 2.8 КБ + JS компонента ~3 КБ ≈ **42 КБ**. Отдельное HTML-превью целиком: 10.6 КБ + 34.8 КБ = 45.4 КБ.

## Как поставить в hero

```tsx
import SpaceLogo from "@/components/SpaceLogo";

<section className="bg-[#f7f7f5] px-4 py-16">
  <SpaceLogo />
</section>
```

Компонент тянется на ширину контейнера (макс. 1100px). Уже 640px знак с надписью укрупняются и встают по центру.
Если блок стоит на главной под заставкой `Intro`, анимация пройдёт под ней: тогда стоит монтировать `<SpaceLogo />` после того, как заставка ушла (например, по `key`).

## Что поправить при желании

- Геометрия знака: константы `DOORWAY` и `LEAF` в `SpaceLogo.tsx` (координаты исходного PNG).
- Порядок и скорость «пера»: массив `PENS` (путь, ширина мазка, задержка, длительность).
- В исходном PNG надпись слегка наклонена (~3°), здесь она выровнена по горизонтали.
