# «Свободное пространство»: аутро с логотипом

Минималистичная 2D-анимация: чёрный фон, тонкие белые линии, статичная камера, 5 с.

| Файл | Что это |
|---|---|
| `video/svobodnoe-prostranstvo-outro-1920x1080-60fps.mp4` | Готовое видео, H.264, 1920×1080, 60 к/с, 5,0 с |
| `video/preview.gif` | Превью 960 px, 25 к/с |
| `preview-frames.png` | 9 кадров анимации |
| `logo-source.jpg` | Исходный логотип (референс) |
| `src/render.py` | Скрипт рендера |

Логотип не перерисовывается: анимируются пиксели исходного файла (маски, сдвиги, масштаб), поэтому финальный кадр совпадает с референсом.

## Тайминги

| Время, с | Что происходит |
|---|---|
| 0–0,25 | Темнота |
| 0,25–1,45 | Внешняя рама двери прорисовывается одной линией: верхняя диагональ, левая сторона, нижняя диагональ |
| 1,50–2,10 | Прорисовывается внутреннее полотно двери |
| 1,95–2,65 | Полотно слегка поворачивается на петле (ширина 74 % → 100 %) |
| 1,95–2,80 | Из проёма выходит мягкий белый свет |
| 2,50–4,00 | Строки текста выезжают из проёма вправо (ease-out), буквы появляются по одной, пересекая край двери. Размытие движения: 8 субкадров, затвор 180° |
| 4,00–4,55 | Свечение гаснет, логотип неподвижен |
| 4,35–5,00 | Плавный уход в чёрный |

Тайминги, сила света и ширина поворота задаются константами в начале `src/render.py`.

## Как пересобрать

Нужны Python 3 с `numpy` и `Pillow`, и `ffmpeg`.

```bash
python3 src/render.py logo-source.jpg video/svobodnoe-prostranstvo-outro-1920x1080-60fps.mp4
# отдельные кадры для проверки:
python3 src/render.py logo-source.jpg x --stills 1.0,2.5,4.2 --stills-prefix /tmp/frame
```
