# «Свободное пространство»: анимация логотипа для hero-блока

SVG и CSS без JS и без GSAP. Анимация проигрывается один раз при загрузке и длится 4 с.

## Файлы

| Файл | Что это |
|---|---|
| `hero/index.html` | Демо-страница. Блок между комментариями `HERO: начало` и `HERO: конец` переносится на сайт как есть |
| `hero/hero.css` | Стили и таймлайн. Все классы начинаются с `sp-` |
| `hero/sketch-lines.webp` | Скетч стадиона, слой контуров: тушь #111 в альфа-канале, 1100×334 |
| `hero/sketch-hatch.webp` | Слой тонкой штриховки крыш, совпадает с контурами при наложении |
| `src/build.py`, `src/params.json` | Сборка: нарезка скетча, буквы в кривые, генерация `index.html` |
| `src/source.png` | Исходник логотипа |
| `src/roboto-condensed-…woff` | Шрифт надписи (Roboto Condensed 500, лицензия OFL в `src/OFL-roboto-condensed.txt`). Шрифт нужен только для сборки, на сайт он не грузится |

**Вес:** 42 КБ без сжатия (HTML 14,8 + CSS 4,5 + WebP 14,2 + 9,4). С gzip HTML занимает около 5 КБ, итого примерно 30 КБ.

## Тайминги

Для всех движений используется кривая `cubic-bezier(0.65, 0, 0.35, 1)`, переменная `--sp-ease`.

| Время, с | Что происходит | Как сделано |
|---|---|---|
| 0–0,55 | Прорисовывается проём | `stroke-dashoffset` 1 → 0 (`pathLength="1"`) |
| 0,45–1,0 | Прорисовывается створка | то же |
| 1,0–1,6 | Створка приоткрывается | `transform: perspective(9em) rotateY(58° → 0)`, петля на левой кромке |
| 1,4–2,4 | Надпись проявляется слева направо | маска: прямоугольник с мягкой кромкой едет по `translateX` |
| 1,4–2,4 | Разрядка сужается с 0,3em до нормы | каждая буква сдвинута на `i × 0,3em` и съезжает в `translateX(0)`. Само свойство `letter-spacing` не анимируется |
| 2,0–3,45 | Контуры стадиона рисуются «пером» | 7 толстых мазков в SVG-маске вдоль линий крыш, `stroke-dashoffset`, мазки идут с задержками |
| 3,0–4,0 | Последней проявляется штриховка | те же мазки на втором слое, со сдвигом на 1 с |

Анимируются только `transform`, `opacity` и `stroke-dashoffset`.

**Reduced motion.** Базовые стили описывают финальный кадр. Стартовые состояния и анимации заданы только внутри `@media (prefers-reduced-motion: no-preference)`, поэтому при `reduce` логотип сразу показан целиком.

**Мобильная версия.** До 640 px логотип занимает до 78vw, а скетч растянут на 118vw и обрезан по краям. По краям у скетча только тени земли, горизонтальной прокрутки нет.

## Пересборка

```bash
pip install pillow numpy fonttools
python3 src/build.py
```

Мазки «пера» (`sketch.pens`: путь, толщина, задержка, длительность), координаты знака и букв задаются в `params.json`. Если меняете мазки, проверьте, что в финальном кадре маски закрывают весь скетч.
